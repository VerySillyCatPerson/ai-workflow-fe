# Design to code

1. Resolve the design reference and retrieve relevant frame or component context.
2. Inspect design tokens, variables, and component mappings where available.
3. Inspect existing repository components and tokens.
4. Map design elements onto existing implementations before creating new ones.
5. Identify unsupported or ambiguous behavior.
6. Implement using project standards.
7. Validate responsive and accessibility behavior.
8. Compare the implementation with design intent and report deviations.
