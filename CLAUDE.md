Claude Code adapter for working **on this repo**. The guide above is
tool-neutral; this file exists only because Claude Code reads `CLAUDE.md`.
`AGENTS.md` is its counterpart — keep both thin, and put every actual rule in
`MAINTAINING.md`.

This is the same pattern consuming projects use: one source, per-tool entry
files. If you find yourself writing a rule here instead of in `MAINTAINING.md`,
that is the leak this architecture exists to prevent.
