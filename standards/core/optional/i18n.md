# Internationalization

**Optional module.** Install only if the project is localized — the manifest
decides. A single-locale product should omit this file rather than carry rules it
will not follow.

- No hardcoded user-facing strings — including accessible names, placeholders,
  `alt`, toasts, and validation messages
- Keys named for **meaning**, not the English text: `form.submitButton`, not `Submit`
- `Intl` for dates, numbers, and plurals. Never concatenate translated fragments —
  word order differs between languages
- New keys land in **every** locale file, `TODO: translate` where unknown
